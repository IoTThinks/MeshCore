Load from USB

Connect the repeater with a USB cable and read its current filter rules directly. Works in Chrome or Edge on a computer. Close any other serial monitor or flasher that uses the port first.

Or paste commands

Paste a list of filter … commands, for example one you copied from here earlier. You can also drop a file on "Drop file here" at the top. Lines that are not filter commands are skipped.

Profiles

The repeater has two profiles, each with its own rules. Only the active profile is used. For example, profile 1 can be your normal setup and profile 2 a lockdown.

    Extra conditions (optional, all must match)

    Only one of these per rule. Path, channel, management and scope cannot be used here.

    Up to 4 one-byte sender hashes (2 hex characters), separated by spaces. Only checked on packet types that carry a sender (req, resp, txt, anonreq, path). All other packet types, such as group messages, adverts and acks, pass this condition.

    The name must be exactly as on the repeater (upper and lower case matter), max 15 characters. Packets without a scope pass this condition.
